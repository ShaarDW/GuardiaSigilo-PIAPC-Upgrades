# Contrato para proyectos alternativos

Un estudiante puede reemplazar Phaser por Unity u otro entorno. La aprobación depende de equivalencia académica, no tecnológica.

## Obligaciones

1. Mantener un repositorio versionado y comprensible.
2. Documentar instalación, apertura, ejecución y validación.
3. Separar lógica de comportamiento de presentación cuando el motor lo permita.
4. Implementar A* o una búsqueda informada equivalente.
5. Implementar una máquina de estados con guardas e invariantes.
6. Comparar al menos otras dos arquitecturas de decisión.
7. Incluir percepción, memoria temporal y navegación.
8. Proporcionar telemetría o trazas equivalentes.
9. Ejecutar pruebas automatizadas o justificar evidencia equivalente.
10. Entregar especificación, plan, permisos, trazabilidad, revisión y producto ejecutable.

## Comandos equivalentes

Si el entorno no usa npm, debe ofrecer procedimientos equivalentes para:

- abrir o instalar;
- ejecutar;
- comprobar tipos o compilar;
- ejecutar pruebas;
- producir una validación completa.

## Unity

Se aceptan Unity Test Framework, compilación del editor, modo de juego y registros estructurados. Las escenas y recursos serializados requieren revisión humana explícita.

## No equivalencias

No reemplazan los requisitos:

- un video sin repositorio;
- una demo ejecutable sin trazabilidad;
- código sin pruebas ni evidencia;
- una mecánica diferente que no permita evaluar navegación y comportamiento;
- una afirmación del agente de que el proyecto funciona.
